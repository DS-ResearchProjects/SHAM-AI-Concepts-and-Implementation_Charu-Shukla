# SHAM-AI: Self-Healing and Adaptive Multi-Modal Anomaly Intelligence

A comprehensive framework for securing Cloud-based Digital Twins (CDTs) through multi-modal anomaly detection and reinforcement learning-based mitigation.

## Overview

SHAM-AI is a novel security framework designed to detect and mitigate multi-modal anomalies in cloud-based digital twin systems. The framework combines **Spiking Neural Network (SNN) Autoencoders**, **Isolation Forest (IF)**, and **Deep Q-Network (DQN) reinforcement learning** to provide robust temporal and spatial anomaly detection with automated, adaptive mitigation policies.

### Key Features

- **Dual Anomaly Detection Pipeline**: Captures both spatial deviations (IF) and temporal patterns (SNN Autoencoder)
- **Reinforcement Learning-Based Mitigation**: DQN agent learns optimal responses (Alert, Pass, Quarantine) for threat mitigation
- **Unified Preprocessing Pipeline**: Single standardization for all downstream components
- **Adaptive Decision Fusion**: Context-aware combination of multiple detection modalities
- **Self-Healing Policies**: Automated recovery and containment strategies

### Performance Highlights

- **Temporal Anomaly Detection**: Up to 21.8% improvement over state-of-the-art baselines
- **Spatial Anomaly Detection**: Up to 18.6% improvement in detection accuracy
- **Mitigation Efficiency**: 23.4% higher efficiency in handling multi-modal anomalies

## Architecture

SHAM-AI consists of three sequentially trained components in a single Jupyter notebook:

### Component 1: SNN Autoencoder (Temporal Anomaly Detection)

The SNN Autoencoder captures temporal patterns in CDT telemetry using spiking neural networks. This component handles all data preprocessing and feature engineering:

- **Preprocessing**: Standardizes heterogeneous CDT telemetry data, handles missing values, and creates sliding windows
- **Training**: Trained exclusively on normal windows to learn normal temporal behavior patterns
- **Output**: Reconstruction error scores representing temporal confidence metrics
- **Windowed Data Generation**: Automatically generates windowed temporal sequences during execution

**Key Responsibilities**:
- Loads raw dataset from CSV file
- Creates balanced train/test split (normal and anomaly samples)
- Fits preprocessing pipeline on normal training data only
- Applies preprocessing to all data (generates non-windowed preprocessed data)
- Generates windowed data for temporal modeling
- Trains SNN model on normal windows exclusively
- Computes anomaly detection threshold from training scores
- Generates reconstruction error scores for test set
- Evaluates model performance with standard metrics

**Outputs Generated**:
- Non-windowed preprocessed training data (normal only)
- Non-windowed preprocessed test data (mixed normal and anomaly)
- Windowed data for SNN training and DQN input
- Reconstruction error scores (temporal confidence)
- Anomaly threshold (98th percentile)
- Binary SNN predictions
- Evaluation metrics (ROC-AUC, Precision, Recall, F1-Score, Accuracy)

### Component 2: Isolation Forest (Spatial Anomaly Detection)

**IMPORTANT: Run this cell AFTER the SNN Autoencoder cell completes.**

Isolation Forest captures spatial point anomalies and deviations from normal data patterns:

- **Training Data**: Uses non-windowed preprocessed data from normal samples (flattened from SNN output)
- **Data Format**: Operates on individual feature rows, not temporal sequences
- **Training Objective**: Learns to isolate normal behavior patterns in feature space
- **Output**: Spatial anomaly scores reflecting deviation magnitude

**Key Responsibilities**:
- Takes non-windowed preprocessed data generated by SNN Autoencoder
- Trains on non-windowed normal samples only
- Detects spatial outliers and point anomalies in feature space
- Generates anomaly scores for each data point
- Computes accuracy metrics against ground truth labels

**Outputs Generated**:
- Spatial anomaly scores (confidence metric from IF)
- Binary IF predictions
- Evaluation metrics (ROC-AUC, Precision, Recall, F1-Score)

### Component 3: DQN Agent (Reinforcement Learning-Based Decision Making)

**IMPORTANT: Run this cell AFTER both SNN and Isolation Forest cells complete.**

The DQN agent learns optimal mitigation policies by combining both temporal and spatial anomaly information:

- **Training Data**: Windowed data and anomaly scores (generated in SNN component)
- **Inputs**: Spatial scores (IF, flattened to match windowed dimensions) + Temporal confidence (SNN)
- **Output**: Three decision actions for each window

**Decision Actions**:
- **Pass**: Allow operation to continue (low-confidence anomaly)
- **Alert**: Notify system administrator with high-priority alert (medium confidence)
- **Quarantine**: Isolate affected system component (confirmed threat, high confidence)

**Key Responsibilities**:
- Combines multi-modal anomaly information from SNN and IF
- Trains on balanced dataset of normal and anomaly samples
- Learns context-aware decision policies
- Generates final mitigation decisions
- Evaluates decision accuracy

**Outputs Generated**:
- DQN decision indices (0=Pass, 1=Alert, 2=Quarantine)
- Decision confidence scores
- Evaluation metrics for decision accuracy

## Data Files

The repository uses a single raw dataset that is automatically processed:

- **`data/raw_dataset.csv`**: Raw input dataset containing both normal and anomaly samples
  - Automatically processed by SNN component

**Auto-Generated Data During Execution**:
- **Non-windowed preprocessed data**: Generated by SNN component preprocessing step; used by Isolation Forest to train on individual feature rows
- **Windowed data**: Generated by SNN component for temporal modeling; used by SNN Autoencoder and DQN Agent
- **Flattened IF scores**: Isolation Forest outputs per individual sample; these are aligned with windowed data for DQN input through proper indexing/reshaping

## Model Components

### SNN Autoencoder
- 2-layer neural network with Leaky Integrate-and-Fire neurons
- Encodes temporal patterns in spike train format
- Reconstructs patterns to compute error scores
- Trained on normal windows only
- Generates both windowed and non-windowed preprocessed data

### Isolation Forest
- Ensemble of isolation trees for anomaly detection
- Captures spatial deviations in feature space
- **Trained exclusively on non-windowed preprocessed data**
- Flattens windowed context to detect point anomalies
- Fast and effective for high-dimensional data
- Trained on normal samples only

### DQN (Deep Q-Network)
- Multi-layer perceptron learning Q-values for decision making
- Takes combined spatial (flattened IF scores) and temporal (windowed SNN) anomaly features as input
- Outputs Q-values for three decision actions
- Trained on balanced normal and anomaly samples
- Uses windowed data for temporal context and flattened IF scores for spatial context
